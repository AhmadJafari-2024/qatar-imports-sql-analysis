# Data Source

Dataset: Qatar Imports 2025–2026

Source: State of Qatar Open Data Portal

The dataset contains approximately 252,000 records and includes:

- Year
- Quarter
- Month
- HS12 product code
- Product description
- Country of origin
- Quantity
- Weight in kilograms
- Import value in Qatari Riyals

The full dataset is available from the official Qatar Open Data Portal.
https://www.data.gov.qa/explore/dataset/qatar-imports-2025-2026/export/
